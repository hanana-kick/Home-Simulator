소음 모델의 가정과 근거

Revision 6 · 주택 벽 높이 2,300mm · 광대역 전달과 저주파 파동

현재 기본 화면은 9절의 50Hz–5kHz 광대역 이웃집 비교입니다. 8절은 저주파 파동, 1–6절은 기존 실내 분포,7절은 교체된 이전 이웃집 모델의 기록입니다. 현장 데이터 없이 계산한 수치를 실제 주택의 측정 소음도로 해석할 수 없습니다.

1. 일반 실크벽지와 벽체

국내 실크벽지는 종이 기재 위에 PVC를 코팅한 마감입니다. 벽지의 표면 흡음과 벽체 전체의 차음은 별도 물성입니다. 이 주택의 벽체 구조는 확인되지 않았으므로 기본 차음값은 약 200mm 조적·콘크리트를 가정하며, 경량벽은 민감도 비교용입니다. 욕실은 기존 타일 마감을 유지합니다.

재료 설명: LX Z:IN 벽지 종류 안내. 실크벽지의 흡음계수는 해당 제품의 시험성적이 없어 단단한 표면의 대체값을 사용합니다.

3. 소음원 크기와 높낮이

소음 크기는 자유음장 1m 거리에서의 dBA입니다. 방 안에서는 반사음이 더해지므로 실제 1m 지점의 결과가 더 클 수 있습니다. 목소리 프리셋은 시나리오 선택값이며 개인의 음량을 측정한 값이 아닙니다.

사람 음성은 기본주파수 F0의 배음과 고정된 발성 공명 분포, 작은 무성음 성분을 합성한 대역 모델입니다. F0를 변경할 때마다 전체 A보정 에너지를 다시 정규화하여 지정한 dBA를 유지합니다. 음색 미리듣기는 성질을 구분하기 위한 합성음으로, 자연 음성·측정용 기준음이나 보정된 스피커 출력이 아닙니다.

핑크 노이즈는 옥타브별 같은 에너지, 화이트 노이즈는 대역 폭에 비례하는 에너지, 순음은 선택한 주파수 주변 대역에 분배합니다. 각 소음은 모두 같은 기준으로 정규화됩니다.

4. 거리 감쇠와 방 사이 전달

L직접,b = L1m,b − 20 log10(max(거리, 0.25m)) − Σ 투과손실b
τb = 10^(−투과손실b / 10)
L합계,A = 10 log10(Σ 10^((Lb + Ab) / 10))

소음원·청취점의 높이를 포함한 3차원 거리를 사용합니다. 직접 경로와 실제 벽·창·문을 교차 검사합니다. 열림으로 지정한 창·문은 해당 면의 투과손실을 제거합니다.

각 방의 벽·바닥·천장 및 가구 흡음면적을 계산하고, 공유 벽과 개구부의 면적 × 투과율로 방별 확산음 에너지 수지를 함께 풉니다. 따라서 문이 소음원과 청취점의 직선상에 없어도 방 사이로 전달되는 확산음이 달라집니다. 실외는 잔향이 없는 공간으로 취급합니다.

직접음·잔향음 에너지 모델의 근거: Arup Strutt의 룸 상수 기반 잔향음. 방 사이 에너지 결합 개념: COMSOL Room Coupling. 이 프로그램이 COMSOL 해석기를 사용한다는 의미는 아닙니다.

5. 화면을 읽는 방법

  • S는 소음원, R은 청취점입니다. 클릭·드래그·좌표 입력으로 이동합니다.
  • 분포도의 색은 청취 높이에서의 소음원과 배경 소음 에너지 합계입니다. 색 범위는 20–95dBA로 고정하여 조건 간 비교가 가능합니다.
  • 각 방의 숫자는 해당 방 중앙에서의 값입니다. 공간 전체 평균은 아닙니다.
  • 주파수 막대는 배경 소음을 제외한 소음원 기여의 A보정 전 대역 음압입니다.
  • 잔향시간은 이웃 공간으로 빠져나가는 에너지를 손실로 취급한 국소 Sabine 추정입니다. 연결된 방 전체의 후기 잔향시간과 다를 수 있습니다.
  • 3D 뷰어의 단면·천장 생략은 계산에 영향을 주지 않습니다. 실내는 2,300mm 높이의 천장이 있는 조건입니다.

6. 에너지 모델에서 재현하지 않는 현상

벽·바닥의 진동, 층간 충격음, 구조를 통한 우회 전달, 세부 문틈 누설, 저주파 정상파와 위상 간섭, 모서리 회절, 발성 방향에 따른 지향성, 음성 명료도(STI)는 계산하지 않습니다. 낮은 주파수에서 확산음 가정이 잘 맞지 않는 작은 방의 결과도 비교용 추정입니다. 결과를 현장 실측값이나 방음 성능 인증으로 사용할 수 없습니다.

7. 이전 이웃집 모델 · Revision 4 기록

이 절은 교체된 7대역 모델의 기록입니다. 현재 기본 화면은 아래 9절의 21대역 모델을 사용합니다. 이 절의 계산식과 예전 수치는 현재 광대역 결과에 적용하지 않습니다.

사용자가 이웃집이 작업실 벽에 붙어 있다고 지정했습니다. 기본 접면을 작업실의 도면 위쪽 벽으로 고정했습니다. 이는 해당 방에서 유일하게 다른 실내 공간에 접하지 않는 면이며 실제 북쪽 방위를 뜻하지 않습니다. 이웃 방의 크기·실제 벽체·틈새·배경소음은 아직 가정값입니다. 이웃집 영향 화면의 도식은 축척이 없으며, 다른 접면 선택은 비교 조건입니다.

대화·노래 크기는 발성자와 방식에 따라 달라집니다. Monson 등의 JASA 연구(2012), Table I는 훈련받은 가창자들의 1m 비가중 평균을 보통 대화 62.0dB SPL, 보통 노래 73.9dB SPL로 보고했습니다. 이는 위 표의 dBA와 동일한 지표가 아닙니다. Boren 등의 AES 연구(2013)에서는 일부 발성자가 평균 90dBA를 넘었습니다. 따라서 노래 85dBA는 상한이 아닙니다. 유튜브라는 플랫폼에 대응하는 표준 방 안 음압은 없으며, 방송 프리셋은 진행자의 말하기와 큰 반응을 가정한 값입니다.

노래는 지정한 기본주파수와 크기의 대표 음성 스펙트럼으로 단순화합니다. 곡 전체, 가사, 실제 발성 주법을 재현하지 않습니다. 기본 프리셋에는 반주·스피커 재생음을 넣지 않았습니다. 스피커를 켜면 같은 위치의 핑크 노이즈 대용 스펙트럼을 에너지로 더하며, 재생음의 크기와 활동 비율을 별도로 지정합니다. 영상 시청 모드는 발성을 끄고 스피커 재생음만 계산합니다. 125Hz 미만의 서브우퍼 성분은 계산 범위 밖입니다.

시간 평균과 배경소음

E기간 = d × [(1−f) × E평소 + f × E큰소리] + ds × E스피커
L기간 = 10 log10(E기간)
L배경포함 = 10 log10(E기간 + 10^(L배경/10))

d는 전체 시간 중 발성 비율, f는 발성 시간 중 큰 소리 구간의 비율, ds는 스피커 재생 비율입니다. d와 f는 측정 통계가 아닌 입력값입니다. 발성을 멈춰도 켜진 스피커와 배경소음은 계속 남을 수 있으므로 각각 분리해 계산합니다. dBA 값을 산술 평균하지 않습니다.

이웃 방으로 전달되는 공기 소리

공유 벽은 선택한 실제 외벽의 불투명한 구간만 사용하고 창·문 개구부는 공유 면적에서 제외합니다. 입력 면적이 해당 벽의 가능한 면적보다 크면 제한합니다. 층간 전달 면적은 우리집 방과 이웃 방 바닥 면적 중 작은 값 이하로 제한합니다. 공유 벽과 위·아래층 경로는 선택한 경계에 도달한 직접 입사 에너지와 해당 방의 확산음을 합하고, 대역별 투과율과 경계 면적을 적용합니다. 이웃 방의 바닥 면적·높이·닫힌 방 잔향시간으로 흡음 면적을 정합니다. 결과는 가상 이웃 방의 확산음 평균이며 특정 귀 위치나 원래 소음 지도의 청취점 수치와 같은 값이 아닙니다. 수음실에서 다시 원래 집으로 돌아오는 에너지와 구조를 통한 우회 전달은 풀지 않는 일방향 근사입니다.

τb = 10^(−TLb/10)
A닫힌방 = 0.161 × 이웃 방 부피 / 닫힌 방 잔향시간
E이웃,b = τb × (S × E확산,b + 4 × P직접입사,b) / (A닫힌방 + S × τb)

이는 확산음만 있고 투과율이 낮을 때 L2 = L1 − TL + 10 log10(S/A)의 실간 전달식에 접근합니다. 단일 Rw·STC 등급을 dBA에서 그대로 빼지 않습니다. 경계 면적과 입사각을 반영하며 가까운 소음원에서 면적/거리 제곱 근사로 에너지가 발산하지 않도록 유한 면적을 사용합니다.

위·아래층의 바닥 프로필은 ASHRAE 2023 Chapter 49, Table 40의 150mm 콘크리트 바닥·천장 대용값입니다. 125/250/500/1000/2000/4000Hz의 투과손실은 40/40/49/58/67/76dB이며, 표에 없는 8kHz는 4kHz 값을 유지합니다. 실제 슬래브 두께나 구조를 확인한 값이 아닙니다. 발 구르기·의자 이동·바닥과 접촉한 스피커의 진동은 계산하지 않습니다.

다른 건물 경로는 우리집 외벽·창·문에서 방사된 소리가 실외 거리를 지나 이웃 외벽에 입사한 뒤, 이웃 벽·창의 면적별 투과율을 거쳐 들어가는 과정입니다. 우리집 창 상태와 이웃집 창 상태는 별도입니다. 이웃 창을 열면 해당 창의 투과율은 1이며, 열린 창으로 다시 빠져나가는 손실도 흡음 항에 더합니다. Arup Strutt의 외벽 소음 유입식과 같은 자유음장 입사 → 실내 확산음 에너지 관계를 사용합니다. 이웃 건물은 선택한 외벽의 바깥 방향에 평행하게 마주 보는 방으로 가정하며, 실제 건물 배치·차폐·반사를 재현하지 않습니다.

결과 해석

배경소음 30dBA는 기본 가정입니다. 화면의 “배경보다 낮음/높음”은 소음원 기여와 입력한 배경의 수치 차이입니다. 대화 내용을 알아들을 수 있는지, 잠을 방해하는지, 민원이 생기는지의 확정 판정이 아닙니다. 차음 민감도는 이웃 쪽 전달 경계의 닫힌 벽·창 차음만 바꾸며, 우리집 자체의 벽·창 조건은 그대로입니다. 이웃 창의 열린 부분은 투과율 1을 유지합니다. 차음값을 −10/0/+10dB로 바꾼 비교는 추가 가정에 따른 민감도이며 실제 집의 오차 범위나 통계적 신뢰구간이 아닙니다.

8. 3차원 시간영역 음파 시뮬레이션

이 모드는 매 시간 단계마다 공기의 압력 p와 입자속도 u를 수치 적분합니다. 화면의 부호 있는 압력, 도착 지연, 반사, 간섭과 정상파는 계산 결과입니다. 각 방의 평균 dBA에 그림을 덧붙이지 않습니다. 계산은 브라우저의 Web Worker에서 수행하며 GPU나 외부 서버가 필요하지 않습니다.

공기 영역과 실제 접면

실내 전체의 평면, 2.3m 천장과 바닥, 창·문의 위치를 CAD 모델에서 읽습니다. 이웃집은 작업실의 도면 위쪽 벽(X 7.8–10.3m, Z 0m) 건너에 놓입니다. 공유벽 두께는 기존 도면의 0.2m 가정입니다. 이웃 방 폭은 접한 벽의 2.5m, 깊이는 초기 3m이며 2–6m로 조절합니다. 이는 이웃집 전체를 실측한 평면이 아닙니다. 가구·인체·작은 문틈은 파동 격자에 들어가지 않습니다.

공기 중의 지배 방정식

∂p/∂t = −ρ c² ∇·u + ρ c² Q(t) δ(x−xs)
ρ ∂u/∂t = −∇p
c = 343 m/s, ρ = 1.21 kg/m³

격자 중심에 압력, 셀 사이의 면에 유속을 두는 시간영역 유한체적/유한차분 계산입니다. 압력과 속도는 반 시간 간격으로 어긋나며 면의 유속이 한 셀에서 나간 만큼 반대 셀에 들어갑니다. 이웃 방에서 공유벽으로 되돌아오는 파동도 함께 계산합니다.

Z판(ω) = R + j ω m′
t(ω) = 2ρc / (2ρc + Z판(ω))
r(ω) = Z판(ω) / (2ρc + Z판(ω))

m′은 벽의 면밀도(kg/m²), R은 단위 면적당 저항(Pa·s/m)입니다. 두 압력 사이의 차이가 판의 법선 속도를 만들고 양쪽 공기에 작용합니다. 이 식은 이상화된 국소 반응 판의 질량·저항 모델입니다. 실제 조적벽·콘크리트 판의 굽힘강성, 지지조건, 면을 따라 전파되는 진동, 일치효과와 구조 우회 전달은 포함하지 않습니다. 기존 7개 대역 투과손실표와 같은 벽체 성능을 보장하지 않습니다.

마감 흡음은 표면 흡음률 α에서 얻은 수동 저항성 임피던스 Z = ρc(1+√(1−α))/(1−√(1−α))로 처리합니다. 실크벽지 초기 α는 제품 시험값이 아닌 단단한 저흡음 표면의 비교용 대체값이며 주파수에 무관합니다. 이 설정은 불투명 벽·바닥·천장에 같은 저흡음 대체값으로 적용합니다. 문과 유리는 별도 고정 대체값을 씁니다. 열린 실외 창·문에서 나간 소리는 국소 흡수 경계로 종료합니다. 마당이나 외부 건물 반사를 계산하지 않습니다.

음원과 녹음 파일

소음원은 자유음장 1m에서의 입력 압력에 대응하는 단극자 체적속도로 주입합니다. 관계는 p1m(t) = ρ Q′(t−1/c)/(4π×1m)입니다. 방 안에서는 반사가 더해져 같은 1m 거리라도 더 큰 압력이 생길 수 있습니다. 대화·방송·노래는 선택한 기본주파수와 배음의 합성 발성입니다. 실제 언어 내용이나 가창 기법을 생성하지 않습니다.

전체 스펙트럼에서 1m dBA를 보정한 다음 격자 상한 밖의 성분을 제외합니다. 빠진 고음 에너지를 남은 저음으로 옮기지 않습니다. 따라서 파동 결과를 원래 음성의 전체 대역 dBA로 해석할 수 없습니다.

녹음 파일은 기기 안에서 디코딩해 모노로 합칩니다. 선택한 짧은 시간 구간의 A보정 에너지를 입력한 dBA에 맞춘 뒤, 주파수 필터·샘플레이트 변환·시간창·DC 정리를 적용합니다. 원본 파일 진폭이나 마이크 설정에서 실제 음압을 자동으로 알아내는 기능이 아닙니다. 필터는 상한의 80–100% 구간에서 감쇠하며 시간창 때문에 미세한 대역 밖 누설이 남을 수 있습니다. 파일을 외부로 업로드하지 않습니다.

표시값과 시간

압력 단면은 선택한 높이의 순간 p(Pa)이며, 색상 범위는 사용자가 정한 고정 범례를 씁니다. RMS 표시는 계산 시작부터 현재까지의 p² 평균에서 얻은 대역 제한 dB SPL(re 20µPa)입니다. 소음원이 있는 방과 이웃 방의 프로브는 각각의 격자 관측점이며 방 평균이 아닙니다. 0.15–0.5초의 유한 시간 계산은 긴 시간의 정상상태나 전체 음성 대역의 생활소음 평가를 대신하지 않습니다. 모사 시간과 계산에 걸린 실제 시간을 따로 표시합니다.

검증과 참고 문헌

자동 검증은 자유공간 전파 속도·거리 감쇠, 공유벽의 수동성·질량에 따른 투과 변화, 이론적인 평면파 판 투과, 격자 안정성, 실제 작업실 접면과 음원 대역 제한을 대상으로 합니다. 수치 테스트는 주어진 방정식의 구현을 확인하며 실제 집의 벽체 물성을 검증하지 않습니다.

  • Toyoda (2018), Stability conditions for impedance boundaries in the finite-difference time-domain method: 3차원 흡음 경계의 안정성과 실수 임피던스 대체값.
  • University of Illinois Physics 406, Point Monopole Sound Source: 자유공간 단극자의 구면파와 1/r 압력 관계.
  • ASHRAE Fundamentals, Sound and Vibration: 압력, RMS, 기준 압력 20µPa, A보정과 벽체·구조 전달의 구분.

9. 광대역 이웃집 소음 비교 · Revision 6

계산값의 근거는 입력 데이터입니다. 실제 주택의 차음과 음원을 측정하지 않은 상태에서는 세 시공 가정의 결과를 비교합니다. 그 범위는 실제 집의 오차 한계나 신뢰구간이 아닙니다. 현장 전달곡선을 입력해도 음원·잔향·배경이 가정이라면 화면에 그 미확인 조건을 계속 표시합니다. 기준 충족, 대화 내용의 이해, 민원 가능성을 판정하지 않습니다.

주파수 범위와 공간 평균

50/63/80/100/125/160/200/250/315/400/500/630/800/1000/1250/1600/2000/2500/3150/4000/5000Hz의 21개 명목 1/3옥타브 대역을 각각 계산합니다. 정확한 중심은 1000×10^(k/10), k=−13…7이며, 경계는 중심×10^(±0.05)입니다. 전체 포함 범위는 약 44.67–5623.41Hz입니다. 표시 dBA는 이 대역들의 A보정 에너지 합계이므로 모든 가청 대역을 포함하는 소음계 수치와 같지 않습니다.

광대역 본체는 각 방의 확산음 공간 평균 에너지 수지를 풉니다. 소음원이 어느 방에 있는지와 문·창 상태는 반영하지만 같은 방 안의 미세한 위치·높이 차이, 수신자의 귀 위치나 가구 뒤 차폐는 계산하지 않습니다. 특정 지점의 소음도 지도를 만들어 보이지 않습니다. 저주파에서 작은 방의 확산음 가정이 성립하지 않을 수 있으며, 모드 공진·위상은 별도 저주파 음파 화면의 이상화된 계산 대상입니다.

우리집과 이웃의 연결

벽 높이는 2.3m, 공유벽은 작업실(room6)의 도면 위쪽 폭 2.5m×높이 2.3m=5.75m²입니다. 소음원을 다른 방으로 옮겨도 이 접면은 움직이지 않습니다. 이웃 방의 기본 부피는 7.5m²×2.3m이며 실제 평면이 확인된 값은 아닙니다. 이웃을 추가할 때 해당 작업실 외벽을 통한 기존 외기 손실을 제거하여 같은 벽을 두 번 계산하지 않습니다.

벽체·틈새·우회 전달의 에너지 합산

직접벽 등가투과면적 Bd(f) = [S − S틈새] × 10^(−R(f)/10)
틈새 등가투과면적 Bleak = S틈새  [τ=1인 등가 개구 가정]
우회 등가투과면적 Bf(f) = 10m² × 10^(−Dn,f(f)/10)
B합계(f) = Bd(f) + Bleak + Bf(f)
수음실 A2(f) = 0.16 × V2 / T2(f)
E2(f) = E1(f) × B합계(f) / A2(f)

R은 벽체 요소의 대역별 투과손실, Dn,f는 기준 흡음면적 10m²로 정규화한 전체 우회 경로의 대체값입니다. 실제 접합부별 진동 감소 지수와 벽·바닥의 탄성 구조 해석을 구현한 ISO 12354 전체 모델은 아닙니다. 등가 개구는 실제 틈의 높이·길이·채널 공진을 재현하지 않으며, 입력 면적을 완전 개방 면적에 대응시킨 비교 가정입니다. R이나 Dn,f를 dBA 총량에서 직접 빼지 않고 대역별 선형 에너지로 합칩니다.

수음실 잔향 T2는 전달 손실까지 포함한 전체 감쇠에 대응합니다. 수음실 대각항을 A2로 두고 별도의 B합계를 다시 더하지 않습니다. 음원과 수음실을 양방향으로 결합할 때 내부 흡음 A2−B합계가 음수가 되는 불가능한 조건은 오류로 거절합니다. 불일치한 잔향과 개구 조건을 조용히 보정하지 않습니다.

모든 21대역이 입력되어야 합니다. 누락 대역·빈 셀·중복 주파수·NaN은 거절하며, 일부 주파수밖에 없는 측정값을 나머지 대역에 자동 확장하지 않습니다. ISO 12354-1의 기본 상세 예측 범위는 100–3150Hz이며 저역 확장은 해당 요소·접합부 데이터가 있을 때 다룹니다. 이 앱이 50–5000Hz 배열을 지원한다는 사실은 전 대역에서 표준 수준의 예측 정확도를 보증하지 않습니다.

자료 출처와 미확인 시공 조건

고밀도 콘크리트·조적 기본 곡선은 UFC 3-450-01 (2022), Table C-8의 8inch(약203mm) 설계 참고값입니다. 31/63/125/250/500/1000/2000/4000/8000Hz의 34/36/37/41/45/49/53/57/61dB를 로그 주파수에서 보간합니다. 우리집 벽 두께·면밀도를 측정한 값이 아닙니다. 실내 목문은 Table C-13의 개스킷 없는 중공 목문 참고값을 사용합니다.

실험실 경량벽 예시는 NRC Halliwell 외, Gypsum board walls: transmission loss data (1998), p77, TL-93-002의 21대역 측정값입니다. 구성은 양면16mm Type-X 석고보드 한 겹,90mm 강재 스터드406mm 간격,75mm 미네랄 섬유입니다. 이 자료를 선택하는 것은 해당 실험실 조립체를 비교하는 것이며 한국 주택의 벽을 그 구조로 확인한 것이 아닙니다. 실크벽지·바닥·천장·가구 흡음은 종전 표의 비교 대용값을 보간하며 재료 시험값이 없습니다.

세 시공 가정은 입력한 중앙조건을 기준으로 벽체 R ±8dB, 등가틈새 면적 ×10/×1/×0.1, 우회 Dn,f ±8dB를 함께 바꿉니다. 수치는 사용자가 구조를 모를 때 민감도를 드러내기 위한 설정이며 확률분포·측정 오차범위가 아닙니다. 현장 R′/DnT 모드에서는 이 세 가정을 제거하고 입력 곡선 한 조건으로 계산합니다. 측정 불확도가 제공되지 않았는데 ±범위를 자동 부여하지 않습니다.

실제 녹음의 스펙트럼과 시간 통계

선택한 녹음 구간에 1초 Hann 분석창을 0.5초 간격으로 적용합니다. 양끝을 반사 연장하고, 반사로 중복된 표본까지 포함한 제곱 창 가중치 합으로 정규화하여 전체 구간의 에너지를 보존합니다. 마지막 짧은 블록도 실제 길이로 가중합니다. 전체 구간의 모든 FFT 빈에 A보정을 적용한 에너지로 보정 이득 하나를 먼저 정하고, 그 뒤 21대역 밖을 제외합니다. 대역 밖 에너지를 남은 소리에 다시 분배하지 않습니다. 디지털 진폭은 측정 음압이 아니며 사용자가 지정한 자유음장 1m 전체대역 LAeq에 대응시킨 입력입니다. 단순한 녹음 파일 선택으로 실제 음량을 알아내지 않습니다.

구간 LAeq는 실제 녹음의 쉼·음량 변화를 포함한 에너지 평균입니다. 녹음을 사용하는 활동에는 합성 발성률·큰소리 비율·별도 스피커를 다시 더하지 않습니다. 구간 최대는 평활 스펙트럼의 1초 평균 중 최대이며, 0.5초 간격의 후보와 마지막 끝맞춤 구간에서 찾습니다. 1초 분석창으로 평활된 값이므로 직사각 시간창의 정밀 소음계 측정값, 순간 피크나 LAFmax가 아닙니다. 각 대역에서 서로 다른 시각의 최대를 골라 합치는 방식도 사용하지 않습니다. 녹음은 로컬에서 처리하며 프로젝트에는 분석된 대역·시간 통계만 저장하고 원본 오디오를 포함하지 않습니다.

FFT 합산은 IEC 61260 등급을 인증한 필터 뱅크가 아닙니다. 유한 시간 블록의 경계에서 스펙트럼 누설이 있고, 영 채움에 따른 빈 간격이 실제 주파수 분해능을 높여주지는 않습니다. 분석대역에 남은 A가중 에너지 비율과 구간 길이를 결과에 표시합니다.

배경소음과 결과의 의미

전달 소음과 배경소음은 각각 표시하고, 합계는 에너지로 더합니다. 배경의 총 dBA 한 숫자만 있으면 주파수별 배경 형태는 미확인입니다. 그런 경우 대역 배경과 대역 차이는 명시된 스펙트럼 가정에 의존합니다. 주파수별 배경을 입력하면 해당 대역값을 사용합니다. '전달음−배경'은 수치 차이이며 소리가 들리지 않거나 대화 내용이 이해되지 않는다는 판정이 아닙니다. STI·명료도 점수는 제공하지 않습니다.

검증 범위와 현장 검증

자동 테스트는 정규화된 전달식, R′/DnT 정의의 동등성, 경로 합산·누기 하한·잔향 중복 방지·방 에너지 수지·디지털 녹음 이득 불변성·대역 외 에너지 제외·프로젝트 입력 검증을 대상으로 합니다. 이는 계산식의 구현 검증입니다. 실제 주택에서의 오차를 확인한 검증 자료는 아직 없습니다.

  • ISO 12354-1:2017: 요소·직접·측로 전달 데이터를 이용한 건물 공기전달 차음 예측. 이 앱은 전체 표준 구현·인증을 주장하지 않습니다.
  • ISO 16283-1:2014: 건물 두 실 사이의 현장 공기전달 차음 측정. 실제 검증에는 음원실·수음실의 공간 평균 대역 음압, 배경, 잔향과 측정 절차가 필요합니다.
  • NRC soundPATHS: 직접 전달과 구조 접합부를 통한 우회 전달의 구분과 건물 전체 경로 평가.
