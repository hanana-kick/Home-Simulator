# Home Simulator

원본 치수 평면도와 3D 참고 이미지 3장으로 재구성한 주택 **3D CAD 모델 및 웹 뷰어**입니다.

**웹 뷰어 (GitHub Pages):** https://hanana-kick.github.io/Home-Simulator/

## Revision 5 · 시간영역 3차원 음파

- 기본 화면 **음파 시뮬레이션**에서 공기의 음압(Pa)과 입자속도를 시간에 따라 수치 적분합니다. 파동의 도착 지연, 반사, 간섭, 정상파, 열린 문에서의 회절과 벽을 통한 전달이 계산에 포함됩니다.
- **이웃집은 작업실 벽에 붙어 있다**는 사용자 정보를 반영했습니다. 도면에서 작업실의 유일한 외부 접면인 위쪽 벽(X 7.8–10.3m, Z 0m)을 공유벽으로 사용합니다. 방위가 북쪽이라는 뜻은 아닙니다.
- 우리집 실내 전체와 이웃 방의 공기 영역을 3차원 격자로 계산합니다. 벽 높이는 2.3m입니다. 이웃 방은 폭 2.5m, 깊이 3m를 초기 가정으로 사용하며 깊이를 조절할 수 있습니다.
- 공유벽은 면밀도와 저항을 갖는 **이상화된 얇은 판 경계**입니다. 압력차가 벽의 속도를 만들고 양쪽 공기에 반대로 작용하므로 반사·투과가 양방향으로 결합됩니다. 실측 콘크리트의 굽힘·지지조건·일치효과·구조 우회 전달을 재현한 모델은 아닙니다.
- 실크벽지의 흡음은 주파수에 무관한 국소 표면 임피던스 대체값으로 둡니다. 벽체의 면밀도·저항과 구분합니다. 가구의 상세 형상과 흡음은 파동 모드에 포함하지 않습니다.
- 0.15/0.10/0.075m 격자의 해석 상한은 파장당 10셀 기준으로 각각 약 229/343/457Hz입니다. 시간 간격은 3차원 CFL 제한에 안전계수를 적용합니다. 높이 방향 간격은 2.3m를 정확히 나누며 가로 격자보다 작거나 같습니다.
- 대화·방송·노래의 합성 발성, 순음, 펄스를 입력합니다. 원래 전체 스펙트럼에서 격자 상한 밖의 성분을 제거하고 남은 저음을 전체 dBA로 다시 증폭하지 않습니다.
- 녹음 파일을 기기에서 읽어 선택 구간의 음파를 입력할 수 있습니다. 파일의 디지털 진폭은 소음계 측정값이 아니며, 사용자가 지정한 1m dBA로 전체 대역을 보정한 뒤 계산 대역을 통과시킵니다. 파일은 서버로 전송하지 않습니다.
- 부호 있는 순간 압력, 누적 RMS의 **대역 제한 dB SPL**, 소음원이 있는 방·이웃 방 관측점의 압력 기록을 표시합니다. 화면의 모사 시간은 실제 계산 소요시간과 별도입니다. 짧은 계산 구간의 RMS는 정상상태나 전체 음성 대역의 dBA가 아닙니다.
- 계산은 Web Worker에서 명시적으로 시작하며 중단·일시정지가 가능합니다. 설정을 변경한 뒤에는 새 계산을 시작합니다. 기존 에너지 비교는 `?mode=neighbor`, 실내 분포는 `?mode=noise`, 3D CAD는 `?mode=viewer`에서 계속 사용할 수 있습니다.

이론식·경계조건·검증 범위는 [계산 근거의 파동 해석 항목](https://hanana-kick.github.io/Home-Simulator/acoustic-notes.html#waves)에 정리합니다.

## Revision 4.1 · 이웃집 영향 비교

- **이웃집 영향**에서 일상 대화, 유튜브 방송 진행, 노래를 나란히 비교합니다.
- 벽을 공유하는 옆집, 윗집/아랫집의 공기 전달, 실외를 거쳐 다른 건물로 들어가는 경로를 선택합니다.
- 기본 접면은 작업실 위쪽 공유벽이며, 이웃 방 크기·차음·창 상태는 가정값입니다. 다른 경계도 비교할 수 있으며 결과는 **가정한 이웃 방의 평균**입니다.
- 1m 발성 크기의 초기 비교값은 대화 60/66dBA, 방송 66/78dBA, 노래 75/85dBA(평소/큰 소리 구간)입니다. 개인의 실측값이나 플랫폼 표준이 아니며 모두 수정할 수 있습니다.
- 발성 시간 비율과 큰 소리 구간 비율을 에너지로 합산합니다. 스피커는 크기와 재생 시간 비율을 독립적으로 설정합니다. 유튜브 영상 시청은 발성을 끄고 스피커만 비교합니다.
- 이웃 방의 소음원 기여, 배경 포함 총량, 큰 소리 구간, 시간 평균, 차음 ±10dB 가정의 민감도를 구분합니다. “안 들림”이나 법적 기준 충족으로 판정하지 않습니다.
- 우리집 내부의 소음원 위치와 문·창 설정은 소음 분포 화면과 공유합니다. 실제 구조의 우회 전달·충격음·저주파 공진·125Hz 미만 서브우퍼 성분은 재현하지 않습니다.

## Revision 4 · 소음 시뮬레이션

- 벽 높이 **2,300mm**를 3D 뷰어와 STEP/DXF/GLB/SCAD에 동일하게 적용했습니다.
- 평면도에서 소음원(S)과 청취점(R)을 클릭·드래그하거나 좌표·높이로 지정합니다.
- 사람 음성, 핑크 노이즈, 화이트 노이즈, 순음을 선택하고 **자유음장 1m 기준 dBA**를 조절합니다.
- 음성 기본주파수 F0(80–350Hz)와 크기를 독립적으로 조절합니다. 높낮이를 바꿔도 1m dBA는 유지됩니다.
- 일반 PVC 코팅 실크벽지의 저흡음 표면을 가정합니다. 벽체 차음과 마감 흡음은 분리합니다.
- 창·문 열림, 벽체 가정, 가구 추가 흡음, 배경 소음을 비교합니다.
- 고정 범례의 소음 분포, 청취점 소음원 기여/배경, 각 방 중앙의 예상 dBA, 옥타브별 결과를 제공합니다.

**추정 모델:** 125Hz–8kHz 옥타브 에너지, 거리 감쇠, 물리적인 벽·개구부 투과와 방 사이 확산음 전달. 실제 벽체 구조는 확인되지 않았으며, 기본값은 약 200mm 조적·콘크리트 가정입니다. 실크벽지 흡음은 제품 시험값이 아닌 단단한 표면의 대체값입니다. 구조전달음·충격음·우회 전달·저주파 공진·음성 명료도는 계산하지 않습니다. [모델 수치와 출처](https://hanana-kick.github.io/Home-Simulator/acoustic-notes.html).

## 3D 뷰어 기능

- 전체 높이, 1,080mm 단면, 평면 보기를 전환
- 3D 회전·확대·이동, 평면 보기에서 수직 시점 유지
- 공간 선택, 면적·치수 표시 및 가구·창호·마당·레이블 표시 전환
- 참고 이미지 4장 확대·비교
- WebGL이 없으면 CPU 소프트웨어 렌더러로 전환
- 브라우저에서 STEP, DXF, GLB, SCAD 다운로드

## CAD 파일

| 경로 | 형식 | 단위 |
|---|---|---|
| [cad/floorplan_3d.step](cad/floorplan_3d.step) | STEP AP214, 250개 faceted BREP 솔리드 | mm |
| [cad/floorplan_3d.dxf](cad/floorplan_3d.dxf) | DXF, 레이어 10개, 6,821개 3DFACE | mm |
| [cad/floorplan_3d.glb](cad/floorplan_3d.glb) | glTF 2.0, 재질 포함, 349개 객체 | m |
| [cad/floorplan_3d.scad](cad/floorplan_3d.scad) | OpenSCAD 편집용 기하 | mm |
| [cad/model.json](cad/model.json) | 공간·객체·재질·가정값 모델 데이터 | m |

웹 코드는 `source/`의 HTML/CSS/JavaScript 모듈로 관리합니다. 모델 데이터, CAD, 참고 이미지는 상대 경로로 불러오며 외부 라이브러리/CDN 없이 동작합니다. 빌드는 `_site/`를 만들고 `build-manifest.json`에 주요 파일 SHA-256을 기록합니다. 기존 단일 HTML 조각은 Git 이력에 보존되어 있습니다.

## 자동 배포

`main`에 커밋하면 [.github/workflows/pages.yml](.github/workflows/pages.yml)이 음향·CAD 정합성 테스트 후 정적 사이트를 빌드하고 `_site`를 GitHub Pages로 배포합니다.

- **처음 사용한다면** 저장소의 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택해야 합니다.
- 개인 GitHub Free에서는 Pages가 **공개 저장소**에서만 지원됩니다. 개인 Pro 이상에서는 비공개 저장소에서 제공할 수 있지만 Pages 사이트는 일반적으로 공개 접근 가능합니다.
- 배포 상태는 저장소 **Actions**의 `Publish Home Simulator to GitHub Pages`에서 확인합니다.

## 참고 이미지

## 로컬 실행

Node.js 22 이상, 런타임 의존성 없음.

```bash
npm test
npm run build
npm run dev
```

`http://localhost:4173/`에서 실행합니다. `?mode=viewer`는 3D 뷰어로 시작합니다.

## 검증 범위

자동 테스트 43개는 모델/STEP/DXF/GLB/SCAD 높이 정합성, 음원 dBA 정규화, 거리 감쇠, 문 열림, 방 사이 에너지 전달, 공유벽 위치 고정을 검사합니다. 파동 계산은 CFL 제한, 에너지 보존, 평면파의 질량·저항 면 투과 해석해, 격자 세분화에 따른 파장·지연 수렴, 3D 단극자의 절대 압력과 거리 감쇠, 녹음의 A보정과 대역 필터링으로 검증합니다. 음향 결과는 현장 실측으로 보정한 값이 아닙니다.
